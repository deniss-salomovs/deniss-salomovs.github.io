# CLAUDE.md

Guide for AI assistants working on `deniss-salomovs.github.io` — Deniss Šalomovs's portfolio site.

## What this repo is

A static portfolio site hosted on GitHub Pages (user-site for `deniss-salomovs`). No build step — every committed file is shipped as-is.

- `index.html` — single page, three views switched via JS (Projects / Art / Info).
- `core.js` — all behavior: project metadata, gallery rendering, lightbox, navigation.
- `style.css` — single stylesheet, CSS custom properties for design tokens.
- `assets.json` — manifest of media files per project, generated by `asset-manager.html` (browser tool).
- `asset-manager.html` — local utility page that regenerates `assets.json` by scanning directory listings.
- `assets/` — all media (gallery images/videos under `projects/` and `personal-art/`, UI icons under `icons/`, CV PDF).

The gallery flow: clicking a project expands its `gallery-grid`, which fetches `assets.json` and creates `<img>` / `<video>` elements via `createGalleryItem`. Collapsing a project unloads its gallery DOM. Clicking an asset opens a lightbox with prev/next navigation and image zoom.

## The current engagement

**Asset optimization.** The site ships ~600 MB of raw `png/jpg/gif/mp4/mov` with no lazy loading and `<video autoplay preload="auto">` on every gallery video. Target: under 80 MB total via webp/webm + thumbnail siblings, with the gallery loading thumbs and the lightbox loading full quality.

See the project memories for the full client brief and the size baseline.

## The prime rule

> Maintain clean, reusable, self-explaining code. Use memory, skills, and agents.

Concretely:
- Use the skills in `.claude/skills/` for repeatable workflows. Do not improvise ffmpeg invocations — go through `optimize-portfolio-assets`.
- Delegate to the subagents in `.claude/agents/`. Don't pile everything into the main agent. The three agents (`asset-optimizer`, `frontend-loader-engineer`, `portfolio-reviewer`) divide the work cleanly.
- Persist non-obvious decisions and context in memory (`MEMORY.md`), not in scratchpads or transient TODOs.

## Hard constraint

**Visual design and layout are frozen.** Do not change `style.css` semantics, DOM structure, fonts, colours, spacing, or any rendered visual at default zoom. Performance/loading changes only. Layout-shift fixes are allowed if visually invisible. Run the `portfolio-reviewer` agent before any commit.

## Working modes

- "Optimize this folder" / "convert assets" / "сжать ассеты" → invoke the `optimize-portfolio-assets` skill, delegate execution to the `asset-optimizer` agent (one per folder for parallelism).
- "Audit" / "show sizes" / "что ещё не сжато" → invoke the `audit-assets` skill (read-only).
- "Wire up the new manifest" / "make the gallery use thumbnails" → delegate to the `frontend-loader-engineer` agent.
- Pre-commit gate → delegate to the `portfolio-reviewer` agent.

## Toolchain on this machine

- `ffmpeg 8.0.1` (full build) — used for all conversions including animated webp from gifs.
- `node 22` — used for `tools/optimize_assets.mjs` (driver script for the conversion pipeline).
- No `magick`, `cwebp`, or `gifsicle` — don't reach for them.
- Local preview: `python -m http.server 8000` from repo root, or `npx serve .`.
